# LiDAR spatial-clump FVS policy screen

Generated by `runbooks/build_lidar_clump_policy.py`.

- one-hectare LiDAR sample per block;
- 10 m clumps of trees >=20 m, split into 4-10-tree clumps;
- three largest trees reserved per clump;
- remaining clump trees harvested;
- singletons reserved;
- stable 3-digit plot key in the FVS tree list;
- LiDAR TPH scaled to VRI live stems per hectare;
- LiDAR DBH scaled so block BA matches VRI BA;
- tree-level species sampled from VRI composition.

`cuts.csv` has block/entry cut volumes; `block_results.json` has per-block run
records. This is a structural pilot, not a CFI, legal-compliance product or
approved management plan. Blocks 49, 74 and 108 failed the FVS run and are
excluded.
