# Canonical v2 graph

Shared BA/QMD/large-tree/reserve classes derived from the 4-entry GWM state
library. The graph has 32 canonical states, 40 canonical transitions, four
cycles, and one terminal state.

The canonical classes are a policy screen, not a measured KC state assignment.
The cycle edges are supported by the four FVS-BC entries; they do not establish
a sustained-yield harvest level.
