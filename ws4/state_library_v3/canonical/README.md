# Canonical v3 graph

Shared BA/QMD/large-tree/reserve classes derived from the 8-entry GWM state
library. The graph has 35 canonical states, 48 canonical transitions and two
cycles.

The low-regime cycle `BA_LT20 / QMD35+ / LT_LT6 / RES2+` carries a positive
cut once post-FVS clump harvest is counted. That is the cycle the HMZ-constrained
policy uses. The classes are a structural policy screen, not measured KC states.
