# KC H_200y source matrix

This is the KC H source matrix with the feature curves replaced by the 24-plot,
200-year KC PSP FVS-BC curve set.

- 92 tracks
- 552 feature rows
- 98 product rows
- feature horizon 0–200 years
- product curves remain the source H point estimates

Track-to-plot assignment is nearest initial BA/QMD, not a spatial join. The
curves are no-cut FVS-BC projections with tree age 60 and site index 60
placeholders. See `notes/reports/kc-200y-integration.md`.
