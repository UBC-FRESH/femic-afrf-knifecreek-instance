# Route configuration unavailable

The public BC Forest Tenure road-section layer is present as `roads.gpkg`
(44 sections, 59.6 km). A WS4 route configuration is not built because the
inputs it needs are absent:

- no reviewed mill or destination assignment;
- no product-to-destination eligibility table;
- no gate, bridge, or legal-access status;
- no haul, build, or maintenance cost rates; and
- no block-to-network linkage table.

This is an explicit unavailable decision, not a zero-cost road model. The
public road layer is suitable for map context and a structural access check
only.
